# 音乐素材

将音频放入本目录（可放子目录），在游戏“设置 → 音乐与节奏 → 选择音乐”选择。也可直接输入其他目录的完整路径。列表按本机解码器支持的音频格式筛选，文件内容在试听／保存时验证。

选曲后检查或校准 BPM、初始拍位置、每小节拍数和各谱面小节（用 | 分隔），再保存返回。当前保存选中曲目与一套参数，不自动分析音乐，也不为每首曲目保存独立参数方案。正式游戏长度和输掉的错误上限在“游戏规则”设置。

随现有本地示例曲目使用的 90 BPM、4 秒首拍和四四拍只是示例值；均可在设置页修改。BPM 用于目标拍点，音乐按原速播放。

音频文件保留在本机，不随代码提交。默认拍手音效由程序生成，可通过 `audio.clap_path` 指定正式音效。
